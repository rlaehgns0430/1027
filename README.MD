
정렬 알고리즘 실험 분석 결과

이 프로그램은 다양한 정렬 알고리즘의 성능과 특성을 실험하고 분석합니다. 본 README는 아래 10가지 핵심 분석 항목을 다룹니다.

1. 무작위 데이터 실험 결과

• 무작위 데이터 환경에서 세 정렬 알고리즘의 총 비교 횟수와 평균 비교 횟수를 누적 측정하여 비교합니다.


2. 버블 정렬 vs 조기 종료 버블 정렬

• 정렬이 완료되면 반복을 멈추는 조기 종료 조건이 일반 버블 정렬과 비교했을 때 비교 횟수를 얼마나 단축시키는지 확인합니다.


3. 알고리즘별 안정성 검증 방법 및 결과

• 동일한 키를 가진 데이터에 원본 인덱스를 부여하고, 정렬 후에도 이 인덱스 순서가 유지되는지 확인하여 선택·버블·삽입 정렬의 안정성을 판별합니다.


4. 삽입 정렬 조건이 안정성에 미치는 영향

• 삽입 정렬 내부의 위치 비교 조건문을 >로 했을 때와 >=로 했을 때, 동일 키 원소의 순서가 뒤바뀌며 안정성이 깨지는 원리와 결과를 분석합니다.


5. 이미 정렬된 데이터에서의 성능

• 정렬 완료 데이터 상태에서 각 알고리즘이 수행하는 비교 횟수와 데이터 이동 횟수의 특징을 측정합니다.


6. 역순 정렬된 데이터에서의 성능

• 최악의 조건인 역순 정렬 상태에서 각 알고리즘이 가지는 최대 비교 횟수와 최다 데이터 이동 횟수를 기록합니다.


7. 일부 정렬된 데이터에서의 성능

• 데이터의 상당 부분이 정렬되어 있을 때 각 정렬 알고리즘의 연산 횟수가 어떻게 최적화되는지 관찰합니다.


8. 부분 정렬 데이터 생성 방법 및 AI 활용

• 완전 정렬된 데이터에서 정해진 비율만큼 무작위 스왑을 수행하여 부분 정렬 데이터를 생성하는 알고리즘 구조와 인공지능을 활용한 구현 내용을 기술합니다.


9. 초기 정렬 상태가 성능에 미치는 영향

• 입력 데이터의 정렬 상태에 따라 알고리즘별 성능이 어떻게 변화하는지 비교합니다.


10. 알고리즘별 성능 차이 원인 분석

• 제자리 교환 방식을 쓰는 선택 정렬, 인접 원소를 계속 바꾸는 버블 정렬, 적절한 위치를 찾아 삽입하는 삽입 정렬의 원리적 차이가 비교/이동 횟수의 차이를 만드는 이유를 심층 분석합니다.
